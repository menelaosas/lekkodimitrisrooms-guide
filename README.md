# Δρ. Καλογηράτου — Ιστότοπος Παθολόγου

Production-grade Next.js website for a pathologist's private practice.

---

## Architecture Overview

### Why this stack?

| Decision | Rationale |
|---|---|
| **Next.js 14 App Router** | Server Components by default → minimal JS shipped to client. Static generation for all pages = instant load, perfect SEO. |
| **TypeScript (strict)** | Catches bugs at compile time. All props, config data, and API payloads are typed. |
| **Tailwind CSS** | Utility-first keeps styles co-located with markup, no dead CSS in production (PurgeCSS built-in). |
| **Framer Motion** | Best-in-class React animation. Tree-shakeable. Used *only* in Client Components so it doesn't affect server render. |
| **next/font** | Fonts are subsetted, inlined, and served from the same origin — zero CLS, no Google Font waterfall. |
| **next/image** | Automatic WebP/AVIF, lazy loading, and correct aspect ratio — Core Web Vitals optimized. |
| **react-hook-form + zod** | Lightweight, performant form handling with schema validation shared between client and server. |
| **API Route for contact** | No third-party JS on the page. Rate limiting and validation server-side. GDPR-friendly. |

### Rendering strategy

- **Page (`/`)**: Static Generation (SSG) at build time. No data fetching needed, so this is the fastest possible option.
- **`/api/contact`**: Server-side Route Handler (POST only).
- **`/sitemap.xml`** and **`/robots.txt`**: Auto-generated by Next.js.

### Component architecture

```
Server Components (no JS shipped):
  layout.tsx → Navbar → Footer → Hero → About → Services
  CV → Approach → Office → Contact → Stats (shell)

Client Components (minimal, hydrated only where needed):
  Navbar        → scroll detection + mobile menu state
  ProgressBar   → scroll position tracking
  BackToTop     → scroll position tracking
  Stats         → animated counters (IntersectionObserver)
  ContactForm   → form state + fetch
  AnimatedSection, StaggerContainer → Framer Motion scroll triggers
```

### Scroll animation pattern

Each section alternates direction as you scroll:
```
Hero     → fade up        (entry animation, no scroll)
About    → LEFT / RIGHT
Services → fade up stagger
Stats    → fade up
CV       → LEFT / RIGHT
Approach → RIGHT / LEFT
Office   → LEFT / RIGHT
Contact  → LEFT / RIGHT
```

This is controlled entirely in `src/lib/motion.ts` — change variants there to adjust all animations at once.

## Setup Instructions

### Prerequisites

- Node.js 18.17+ (required by Next.js 14)
- npm 9+ or pnpm 8+

### 1. Clone and install

```bash
git clone <your-repo-url>
cd pathologos
npm install
```

### 2. Configure environment variables

```bash
cp .env.local.example .env.local
```

Edit `.env.local` and fill in:
- `NEXT_PUBLIC_FORMSPREE_ENDPOINT` **or** `RESEND_API_KEY` (see Contact Form section below)
- `NEXT_PUBLIC_SITE_URL` → set to `https://pathologoskalogiratou.gr`

### 3. Run development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### 4. Type-check and lint

```bash
npm run type-check
npm run lint
npm run format
```

### 5. Build for production

```bash
npm run build
npm run start
```

## Contact Form Setup

### Recommended: Resend (already wired, just uncomment)

**Why Resend over Formspree for this site?**
- No third-party JavaScript loaded in your HTML → better security, CSP, and performance
- All form data stays within your infrastructure until you choose to send it
- Rate limiting and validation happen server-side before any email is sent
- Free tier: 3,000 emails/month (more than enough for a private practice)
- Simple setup, excellent deliverability

**Steps:**
1. Create an account at [resend.com](https://resend.com)
2. Verify your domain (`pathologoskalogiratou.gr`) by adding DNS records
3. Install the SDK: `npm install resend`
4. Add to `.env.local`:
   ```
   RESEND_API_KEY=re_your_key_here
   CONTACT_EMAIL_TO=info@pathologoskalogiratou.gr
   CONTACT_EMAIL_FROM=noreply@pathologoskalogiratou.gr
   ```
5. In `src/app/api/contact/route.ts`, uncomment the Resend block

### Alternative: Formspree (simpler, no server code)

If you want zero backend code:
1. Create a form at [formspree.io](https://formspree.io) — free for 50 submissions/month
2. In `ContactForm.tsx`, replace the `fetch("/api/contact", ...)` call with:
   ```ts
   const res = await fetch(process.env.NEXT_PUBLIC_FORMSPREE_ENDPOINT!, {
     method: "POST",
     headers: { "Content-Type": "application/json" },
     body: JSON.stringify(data),
   });
   ```
   Note: This sends data to Formspree's servers — verify their GDPR compliance for Greek/EU users.

## Deployment to Vercel (Recommended)

Vercel is the creator of Next.js — zero-config deployment, free tier available.

### Steps

1. **Push to GitHub** (or GitLab/Bitbucket):
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/pathologos.git
   git push -u origin main
   ```

2. **Import on Vercel**:
   - Go to [vercel.com](https://vercel.com) → New Project
   - Import your GitHub repository
   - Vercel auto-detects Next.js — no configuration needed

3. **Set environment variables** in Vercel Dashboard:
   - Project → Settings → Environment Variables
   - Add all variables from `.env.local`

4. **Add your custom domain**:
   - Project → Settings → Domains
   - Add `pathologoskalogiratou.gr` and `www.pathologoskalogiratou.gr`
   - Follow Vercel's DNS instructions (add A/CNAME records at your registrar)

5. **Deploy**:
   - Every push to `main` triggers an automatic deployment
   - Preview deployments are created for every PR

### Vercel free tier limits (Hobby plan)
- 100 GB bandwidth/month
- Serverless function execution: 100 GB-hours/month
- All more than sufficient for a medical practice website
